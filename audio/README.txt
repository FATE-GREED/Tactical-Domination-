Timpa file di folder ini dengan audio milikmu (format mp3, NAMA FILE SAMA). Varian yang
file-nya dihapus akan dilewati; jumlah varian per suara boleh dikurangi.

move-foot-1..3        langkah unit jalan kaki        move-vehicle-1..2   kendaraan bergerak
shoot-rifle-1..3      Infantry                       shoot-auto-1..2     Assault
shoot-sniper-1..2     Sniper                         shoot-rocket-1..2   Anti-Tank
shoot-cannon-1..3     Tank Lapis Baja & Crusher      shoot-mortar-1..2   Montir
hit-1..3              peluru mengenai target         explosion-small-1..2 unit hancur
explosion-big-1..2    bangunan hancur                execute-start       tombol Eksekusi
win / lose            layar Game Over                bgm-plan / bgm-battle musik latar (loop)

bgm-plan diputar saat giliran menyusun rencana, bgm-battle saat eksekusi.
Setelah mengganti file, naikkan CACHE_NAME di service-worker.js agar PWA memuat ulang.
